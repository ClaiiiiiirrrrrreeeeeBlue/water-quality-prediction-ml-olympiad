# 特征工程讲义：尺度、稀疏组合与类别可用性

先理解第 05 课：`r = log1p(result) - m(A×E)`。本课在它的基础上新增三个残差统计。

## 1. 按单位波动标准化

`r_normal = r / (std(t | unit) + 0.03)`。

原始偏差相同，不代表相对波动程度相同。加 0.03 是稳定分母，避免小标准差使比值爆炸。再把 r_normal 按 C 平滑汇总。

## 2. 保留细粒度组合

另外按 A×C、unit×C 汇总原残差，分母为组合样本数加 3。大多数组合很稀疏，平滑能减少只见过一行就过度相信其标签的问题；未见组合回退到 0。

现在有四个残差信号：C 原残差、C 标准化残差、A×C 残差、unit×C 残差，共生成 63 列。

## 3. 模拟类别信息缺失

训练时固定种子，随机遮蔽 30% 的行：C 设为缺失，C 频数和四个 C 相关残差设为 0。验证和推理时不随机遮蔽，只对真实未见类别正常回退。

数据中测试集未见训练 C 的行约 35.56%，但普通随机验证只有约 4.46%。模拟缺失是让模型不要把所有希望放在 C 信息上，而不是给测试集补造标签。

遮蔽比例不是有物理意义的常数，只是经过验证的正则化设置。后面的统一对照改用 20%，同时还有层级先验和模型参数变化，不能把成绩变化全部归给遮蔽比例。

## 4. 仍然需要交叉拟合

四个残差都是目标相关特征，必须仅从训练数据计算。`fit_transform` 的训练编码与 `transform` 的映射不能混用：拿全量训练标签拟合映射后，再直接 transform 同一批训练行，会把自己的信息放进特征。

## 建议的消融

先只删除一个特征组，保留全部其他条件。分别讨论标准化、细粒度组合和缺失模拟，记录 OOF 与波动，而不是只记“加了某列分数就变好”。
