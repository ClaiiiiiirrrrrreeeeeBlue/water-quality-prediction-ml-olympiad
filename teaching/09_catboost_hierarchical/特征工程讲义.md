# 特征工程讲义：给稀有组一个更合适的先验

## 为什么全局均值不够合适

不同 unit 下目标范围和均值差异很大。一个只有少量观测的 A×E 组，如果一律向全局均值收缩，可能被拉向与自身单位不符的水平。

数据统计显示：167 个 A 中有 164 个仅对应一种 unit，几乎每个 C 也只对应一个 E。它提示匿名字段存在层级关系，但不证明具体物理含义或因果关系。

## 层级平滑

- A 均值向其关联 unit 均值收缩；少数 A 对应多个单位时，使用组内单位先验的平均。
- A×E、A×D、A×F 向 A 均值收缩。
- unit×E 向 unit 均值收缩。
- 未见 A 回退到单位均值；未见交叉组合回退父组均值。

例如：`m(A×E) = (sum(t in A×E) + 10 × m(A)) / (count(A×E) + 10)`。

残差基准也改用新的层级 A×E 均值。其余输入组仍为原始字段、类别交叉、频数、组均值/标准差和四个条件残差。

## 07–09 的控制变量

三课使用同样 63 列、外层 seed=42 的五折、内层编码 seed=42、平滑 10、组合残差平滑 3、20% C 信息遮蔽。差别是学习器及其固定模型参数。

07 是 XGB 深度 5；08 是 LightGBM 31 叶子；09 是 CatBoost 深度 6。不能只凭一次 OOF 排名断言算法普遍更好。该数据上的实际 Private 分别为 0.05554、0.05541、0.05496。

## 编码与验证

训练特征由内层交叉拟合生成，验证和测试由训练映射转换。class 的 `stats_fit` 与 `stats_transform` 只处理当前训练部分传入的标签。

阅读代码建议：先看 `xgb_features.py` 的 basic 与 stats_fit，再看 `ensemble_features.py` 中父组先验替换的少量逻辑。不要一开始试图背下所有列名。

## 范围约束

本比赛训练目标处于 [0,1]，沿用原方案在预测后裁剪到这一范围。这是当前数据和方案的约束，不是所有水质回归任务通用的规律。
