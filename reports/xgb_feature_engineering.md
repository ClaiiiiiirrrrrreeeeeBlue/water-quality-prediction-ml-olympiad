## 以数据结构为起点

这些是本地 CSV 的统计事实，而不是根据匿名字段猜出的物理含义：

- 167 个 `categoryA` 中，164 个仅对应一个 `unit`，其余 3 个对应两个单位。
- 2,212 个 `categoryC` 中，2,211 个仅对应一个 `categoryE`，一个对应两个。
- 去掉 `featureF` 后，其余数值字段只有 24 个联合模式，与 `categoryE` 高度重合。
- `unit` 条件下目标尺度和波动不同，直接计算 `categoryC` 的总体目标均值，可能混合不同 `categoryA`、单位和 `categoryE` 的分布。
- 随机 CV 中未见 `categoryC` 的验证行占 4.46%，实际测试占 35.56%。训练时完全可用的类别信息不能假设在测试时都可用。

据此提出的核心假设是：先扣除 A/E 条件下的平均水平，再从 C 分组中提取剩余信息，可能比直接的分组均值编码更有效。匿名字段只能称为 A/E/C 分组，不能未经证实称为某种具体污染物、国家或采样站。

## 最有价值的特征设计

### 1. 基础分组、支持度和不确定性

目标变换为 `t = log1p(result)`，与 RMSLE 使用的误差空间一致。添加五种类别交叉：

`A×E`、`A×D`、`A×F`、`unit×E`、`B×D×F`。

为原始类别与交叉类别添加 `log1p(训练出现次数)`；为 `unit`、A、E、A×E、A×D、A×F、unit×E 添加平滑目标均值和组内目标标准差。

对任一分组 g，平滑均值为：

`m(g) = (sum(t in g) + s × global_mean(t)) / (count(g) + s)`，默认 `s=10`。

稀有组向全局均值收缩，未见组回退全局均值。标准差只在对应训练部分计算，单样本组设为零。

**单纯添加上述均值编码没有提升**：其五折 OOF 为 0.059348，弱于原始 XGB 的 0.058795。这是保留在报告中的负面结果，不能把目标编码本身宣传为本项目的有效创新。

### 2. C 分组的条件残差

在当前编码拟合部分中，先得到 A×E 的平滑均值，然后计算：

`r_i = t_i - m(A_i × E_i)`。

再按 C 分组聚合：

`C_residual(c) = sum(r_i where C_i=c) / (count(C_i=c) + 10)`。

这样提供给 XGB 的是“相对 A/E 基准偏高还是偏低”，而不只是混合多种类别后的总体目标水平。未见 C 的残差特征回退为零。

加入这一列后，五折 OOF 从普通均值编码的 0.059348 降到 0.055119；线上 Private 为 0.05796。它是第一次明确且有对照的特征工程增益。

### 3. 残差增强包

在上面的残差之外，增加三列：

- 按单位波动标准化：`r_normal_i = r_i / (std(t | unit_i) + 0.03)`，再按 C 聚合，分母为样本数加 10。
- 按 A×C 聚合原始残差，分母为组样本数加 3。
- 按 unit×C 聚合原始残差，分母为组样本数加 3。

第一项避免高波动单位完全主导 C 统计；后两项保留同一组合的细粒度信息，同时对稀疏组合收缩。未见组合均回退为零。

增强包将五折 OOF 进一步降至 0.053433。这里验证的是三个新增特征一起加入的增益，未分别做三项的独立消融，因此不能声称每一项都单独贡献同等提升。

### 4. 训练时模拟 C 信息不可用

使用固定随机种子 42，在训练特征中随机选中 30% 的行：

- 将 `categoryC` 设为缺失；
- 将 C 的频数设为零；
- 将四个 C 相关残差特征设为零。

验证、测试和推理时不做随机遮蔽，真实未见类别由训练类别集合转为缺失，并使用回退统计。这是一种针对类别可用性变化的正则化处理，不使用测试标签，也不根据测试 ID 进行手工预测。

30% 不是预先精确确定的最优比例：本地比较了 0%、15%、30%，考虑已观察到的测试未见类别比例，并对 15% / 30% 做了线上检查。30% 方案最终达到 Private 0.05686；应如实说明选择过程，而不是将其包装成完全预先固定的单次盲测。

最终共 63 列：26 原始输入 + 5 类别交叉 + 2 缺失/非零标记 + 12 频数 + 14 分组均值/标准差 + 4 残差。

## 防止目标编码泄漏

所有外层验证样本的标签都不会进入其特征处理器。

在每个外层训练折内，再使用随机 5 折交叉拟合生成训练特征。对一个内层验证块，全部均值、标准差、残差统计均仅从其余内层训练块拟合；之后再用外层全部训练数据拟合映射，处理外层验证与测试。

最终全量模型同样使用内层交叉拟合训练特征，而测试映射使用全部训练标签拟合的统计量。

实际审计：将一行标签加 2，重新生成特征，该行所在内层验证块的所有目标编码完全不变。基础残差和增强残差两种处理均通过该检查。标签修改会影响其他内层块和最终测试映射，这是预期行为。

交叉拟合原则可参照 [scikit-learn TargetEncoder 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.TargetEncoder.html)。这里实现的是带条件残差的自定义处理器，并非直接调用 TargetEncoder。

## 课堂可以讲清楚的项目亮点

故事线是：发现匿名分组的层级关联 → 普通目标编码没有提升 → 扣除条件基准后提取残差信号 → 处理不同单位的波动 → 用缺失模拟应对类别可用性变化 → 用无泄漏交叉拟合和真实提交验证。

XGB 是承载这些特征的算法工具。可复现的数据结构发现、失败与成功的消融，以及对验证局限的解释，才是这一版相对“直接调库”的改进。
